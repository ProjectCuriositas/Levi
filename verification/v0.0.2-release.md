# Lévi v0.0.2 release verification

## Scope

This source release verifies the existing minimal static site generator with
Mognitio v1.0.0, exact compiler source `fd7d91e24154a9cb04069b884cdf5667d5f4b86c`.
The generator, language tests, fixtures and observer behavior are unchanged
from v0.0.1. Compatibility does not imply support for untested future compilers.
No prebuilt executable is distributed.

The initial current-compiler preflight passed all acceptance checks without a
Lévi or Mognitio product fix. Final acceptance uses the exact release source
and the frozen Mognitio 1.0.0 payload. The GitHub Release notes record final
source commits, commands, counts and archive checks.

## Verification

```sh
python3 tools/verify.py --compiler ../Mognitio --evidence evidence/release-0.0.2
python3 tools/regression.py --compiler ../Mognitio --evidence evidence/release-0.0.2
git diff --check
```

Use a fresh evidence directory and the non-root Linux amd64 prerequisites in
the README. Require all 182 external records, 20 named language tests,
37 acceptance conditions, 12 design checks, 24 measurement cells (120 native
samples), and 11 observer negative controls. Do not disable Python assertions.

Also build and test the release source archive without Git metadata using the
frozen compiler payload, compare exact golden HTML for interpreted and isolated
native execution, and verify every archive file against the tagged source.
Source-tree verification and packaged-toolchain acceptance are distinct checks.
Raw evidence is local and ignored; published results are sanitized.

## Limits

The [v0.0.1 limitations](v0.0.1-release.md#limits) remain. There is no HTTP server,
routing, template language, recursive input, asset copying, clean or watch mode,
output rollback, input-size bound, or runtime performance guarantee. Scalar-heavy
native allocation-search overhead is not fixed by this compatibility release.
