# Lévi v0.0.1 release verification

## Scope

This is the initial source release of the minimal static site generator for
Linux amd64. Build with Mognitio v0.14.0, compiler revision
`31eae7795d0152491d80fa57fd017f084e6bf934`. No prebuilt executable is published.
The generated native executable needs no compiler or Python at runtime.

The implementation and observer were accepted at
`25f6d0dc10b6f632da349d34f75622542db01a91`; its tree equals version integration
`067c0fb1dab9a623b0f196f7ac0425bdb9e871e5`. Release preparation changes only
public documentation. The release PR and release notes record the final
validated revision and the main merge targeted by the immutable tag.

## Acceptance checks

From a checkout with the compiler environment configured:

```sh
python3 tools/verify.py --compiler ../Mognitio --evidence evidence/release
python3 tools/regression.py --compiler ../Mognitio --evidence evidence/release
git diff --check
```

Use a fresh evidence directory and a non-root user with the prerequisites
listed in the README. The accepted baseline passed:

- 182 external observation records and 20 named Mognitio tests.
- All 37 acceptance conditions and 12 design checks.
- 11 observer negative controls, including real empty and incomplete suites.
- Byte-exact host/native results, calibrated syscall faults, partial output,
  interrupted-run recovery, and an isolated standalone executable.
- 24 measurement cells with 120 native process samples.

Missing identities, individual failures, external cases, traces, provenance,
or measurement artifacts fail acceptance. The expectation manifest is reviewed
independently from the test discovery results.

Release integration requires the main merge tree to match the tested version
tree. Source archives are also built and exercised without Git metadata,
including the prepared Mognitio suite and exact golden HTML comparisons.
The tag archive must match the committed file bytes. Raw evidence remains
local and ignored; public reporting uses sanitized summaries.

## Limits

Native scalar-heavy processing retains allocation-search overhead. No input
size, wall-time, or memory bound is promised. Acceptance is not evidence that
this performance issue is resolved. The separate earlier stress timeout is
not a successful acceptance check.

Fault injection demonstrates consumer error handling. Artificial ENOENT does
not establish natural failure conditions, and skipped close does not prove
runtime descriptor release. Verification assumes a finite, trusted, stationary
Linux amd64 filesystem; concurrent path replacement and other platforms are
outside the verified scope. There is no HTTP server, routing, recursive input,
Markdown parser, template language, watch mode, or output rollback.
